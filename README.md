# 🛡️ CivicShield AI

## AI-Powered Emergency Coordination & Response System

CivicShield AI is an AI-based emergency response platform designed to help people quickly report and understand emergency situations such as **fires, floods, accidents, and medical emergencies**.

Users can report an emergency using **text or voice**, provide their location, and receive an AI-generated analysis of the situation. The system identifies **nearby hospitals, ambulances, police stations, and fire stations for fire-related emergencies**, along with location, distance, and route information through an interactive map.

The platform also includes **IoT emergency simulation**, incident storage, flood-specific automatic severity assessment, and human verification to support faster and more organized emergency response.

### ✨ Key Features

* 🚨 Emergency reporting through text and voice
* 🎙️ Multilingual voice reporting
* 🧠 AI-based emergency analysis
* 🌊 Automatic severity assessment for floods
* 🏥 Nearby hospitals
* 🚑 Nearby ambulances
* 👮 Nearby police stations
* 🔥 Nearby fire stations for fire emergencies
* 🗺️ Interactive location and route map
* 📡 IoT emergency simulation
* 💾 Incident storage and tracking
* 👤 Human verification

### 🛠️ Technology

**Python • Flask • Google Gemini AI • SQLite • OpenStreetMap • Leaflet • Nominatim • Overpass API • OSRM • JavaScript**

### 🎯 Goal

The goal of CivicShield AI is to provide a **single platform for emergency reporting, AI-assisted situation analysis, nearby emergency-resource discovery, and location-based emergency support**.
